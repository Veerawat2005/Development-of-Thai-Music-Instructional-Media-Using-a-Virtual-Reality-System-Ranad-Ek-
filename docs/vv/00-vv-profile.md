## 2. ระบบของเรา

- ระบบนี้ทำอะไร (2–3 ประโยค): แอป VR บนแว่น Meta Quest 2 ให้ผู้เริ่มเรียนฝึกตีระนาดเอกด้วยมือตามโน้ตไทยได้โดยไม่ต้องมีระนาดจริง มีโหมดตัวอย่าง ฝึก เล่น และทดสอบ พร้อมระบบคะแนนจากความแม่นยำของลูกระนาด มือที่ใช้ และความตรงจังหวะ
- ผู้ใช้หลักและผู้มีส่วนได้ส่วนเสีย (ใครใช้ ใครได้รับผลกระทบ): ผู้ใช้หลักคือผู้เริ่มเรียนระนาดเอก ผู้มีส่วนได้ส่วนเสียคือครูผู้สอนดนตรีไทยและสถาบันที่ใช้เป็นสื่อเสริมการสอน
- ผู้ใช้จริงที่จะชวนมาทำ UAT ได้ (หน่วยงานหรือกลุ่มผู้ใช้ ไม่ต้องใส่ชื่อบุคคล): ผู้เริ่มเรียนดนตรีไทยและผู้สอนดนตรีไทย (มีกลุ่มที่สนใจแล้ว แต่ยังไม่ได้ติดต่อ)
- การ deploy (ทดสอบที่ไหน ใช้งานจริงที่ไหน): ทดสอบด้วย Unity Editor ผ่าน Quest Link บนเครื่องพัฒนา และติดตั้ง (build) ลงแว่น Meta Quest 2 ใช้งานจริงบนแว่น Quest 2 แบบ standalone ไม่มีเซิร์ฟเวอร์และไม่มีฐานข้อมูลภายนอก คะแนนเก็บในเครื่อง

## 3. เอกสารที่มีอยู่แล้ว

- SRS ฉบับที่ / วันที่ / ตำแหน่งไฟล์ใน repo: ยังไม่มี SRS ฉบับแยก ใช้ข้อเสนอโครงงาน SE02 (ENGSE211) ฉบับลงนามแล้วเป็นต้นฉบับ อยู่ที่ `docs/srs/proposal.pdf` ส่วนความต้องการอยู่ในข้อ 3–4 ของข้อเสนอ มี Use Case 11 รายการ (UC-01 ถึง UC-11)
- จำนวนความต้องการ: เชิงฟังก์ชัน 13 ข้อ (FR-01 ถึง FR-13) · เชิงไม่เป็นฟังก์ชัน 9 ข้อ (NFR-01 ถึง NFR-09)
- RTM อยู่ที่: ยังไม่มี
- แบบสถาปัตยกรรม / ER / API spec อยู่ที่: ยังไม่มีเอกสารแยก (ไม่มีฐานข้อมูลและ API ภายนอก)

## 4. สถานะตอนนี้

- Sprint ปัจจุบันและสิ่งที่กำลังทำ: ยังไม่มี Sprint อย่างเป็นทางการ กำลังเตรียมเอกสารตามงานของวิชา (V&V Profile, SRS 1.0, RTM) และพัฒนาต่อบน Unity [ทีมปรับ]
- ส่วนที่ทำเสร็จแล้ว: ต้นแบบระนาดเอกเสมือนใน VR ตีด้วยมือได้ เมนูบทเรียน และบทเรียนฝึกตีตามโน้ตไทย ส่วนระบบคะแนนกับโหมดทดสอบ [ยืนยัน: ติดตั้งใน Unity แล้ว / อยู่ระหว่างติดตั้งและทดสอบ] ปัญหาที่ยังค้าง [ยืนยัน: มุมมองศีรษะหมุนผิดปกติเมื่อใช้ Quest Link ยังเกิดอยู่หรือไม่]
- การทดสอบที่มีอยู่แล้ว (ถ้ายังไม่มี เขียนว่ายังไม่มี): ยังไม่มี automated test และยังไม่ใช้ CI มีเพียงการลองเล่นทดสอบด้วยมือระหว่างพัฒนา

## 5. ส่วนที่ทีมคิดว่าเสี่ยงที่สุด 3 อย่าง

ใช้ในการวางแผนการทดสอบตามความเสี่ยงครั้งที่ 5 (CP2)

| ส่วนของระบบ | ทำไมคิดว่าเสี่ยง | ถ้าพังจะกระทบใคร อย่างไร |
|---|---|---|
| การตรวจจับการตีลูกระนาดและมือที่ใช้ (hit detection / hand tracking) | คะแนนทั้งหมดขึ้นกับการตรวจจับนี้ และการติดตามมือบน Quest 2 ไม่นิ่งเสมอ ผลต่างระหว่างตีตรงลูกกับลูกข้างเคียงมีระยะเล็กมาก | ผู้เรียนได้คะแนนและผลสอบผิด ผู้สอนไม่เชื่อถือสื่อ |
| มุมมองศีรษะและประสิทธิภาพ (เฟรมเรต) บน Quest 2 | เคยพบมุมมองศีรษะหมุนผิดปกติเมื่อใช้ Quest Link และ Quest 2 มีกำลังประมวลผลจำกัด | ผู้ใช้เวียนศีรษะหรือไม่สบาย ใช้งานต่อไม่ได้ ผู้ทดลอง UAT ให้ผลไม่ดี |
| ความถูกต้องของเนื้อหาบทเรียนและเสียงระนาด | โน้ตและวิธีฝึกบางส่วนมาจากข้อมูลของวิทยาลัยนาฏศิลป์ที่ยังไม่ได้ให้ผู้เชี่ยวชาญตรวจยืนยัน และเสียงในแอปอาจต่างจากระนาดจริง | ผู้เรียนจำโน้ตหรือวิธีตีผิด สื่อการสอนให้ความรู้ที่ไม่ถูกต้อง |
