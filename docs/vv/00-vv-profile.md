# V&V Profile (ร่าง — ยึดหัวข้อตามแม่แบบของอาจารย์ แล้วย้ายเนื้อหาไปวาง)

## 1. ทีม
- ชื่อโครงงาน: การพัฒนาสื่อการสอนวิชาดนตรีไทยโดยใช้ระบบจำลองเสมือน (ระนาดเอก)
- ชื่อภาษาอังกฤษ: Development of Thai Music Instructional Media Using a Virtual Reality System (Ranad Ek)
- สมาชิก: วีราวัชร์ สุประดิษฐ์พงศ์ (หัวหน้า) [รหัสนักศึกษา: ____], ชยานันท์ เพชรรักษ์ [รหัสนักศึกษา: ____]
- อาจารย์ที่ปรึกษา: นุรักษ์ ไชยศรี
- Repo: https://github.com/Veerawat2005/Development-of-Thai-Music-Instructional-Media-Using-a-Virtual-Reality-System-Ranad-Ek-

## 2. ระบบ
แอป VR บน Meta Quest 2 ให้ผู้เริ่มเรียนฝึกตีระนาดเอกตามโน้ตไทย มีโหมดตัวอย่าง ฝึก เล่น และทดสอบ พร้อมระบบคะแนนจากความแม่นยำของลูกระนาด มือที่ใช้ และจังหวะ
- เทคโนโลยี: Unity 6 (URP), C#, XR Interaction Toolkit, XR Hands, OpenXR, Meta Quest 2, PlayerPrefs
- ผู้ใช้หลัก: ผู้เริ่มเรียนระนาดเอก
- ไม่มีฐานข้อมูลภายนอกและไม่เก็บข้อมูลส่วนบุคคล (คะแนนเก็บในเครื่อง)

## 3. เอกสารที่มี
- มี: ข้อเสนอโครงงาน ENGSE211 (ผ่านแล้ว ลงนามครบ), Use Case Diagram, ความต้องการ (ข้อ 3–4 ฉบับแก้)
- ยังไม่มี: SRS ฉบับแยก, RTM, เอกสารออกแบบ, UI prototype แบบเป็นทางการ, แผน Sprint/Product backlog, แผนทดสอบ

## 4. สถานะตอนนี้
- ต้นแบบ VR ระนาดเอกตีด้วยมือได้ มีเมนูบทเรียน
- ระบบคะแนนและโหมดทดสอบ: เขียนสคริปต์แล้ว อยู่ระหว่างติดตั้งและทดสอบใน Unity [ยืนยันสถานะจริงก่อนส่ง]
- ยังมีปัญหาค้าง: มุมมองศีรษะหมุนผิดปกติเมื่อใช้ Quest Link
- automated test: ยังไม่มี, CI: ยังไม่ใช้
- ความคืบหน้าโดยประมาณ: 26–50%

## 5. ส่วนที่เสี่ยง 3 อย่าง
| # | ส่วนที่เสี่ยง | เหตุผล | ผลกระทบถ้าผิด |
|---|---|---|---|
| 1 | การตรวจจับการตีลูกระนาดและมือที่ใช้ (hit detection / hand tracking) | คะแนนทั้งหมดขึ้นกับตรงนี้ และการติดตามมือบน Quest 2 ไม่นิ่งเสมอ | ผู้เรียนได้คะแนนผิด เสียความน่าเชื่อถือของสื่อ |
| 2 | มุมมองศีรษะและประสิทธิภาพ (เฟรมเรต) บน Quest 2 | พบมุมมองหมุนผิดปกติเมื่อใช้ Quest Link; เฟรมเรตต่ำทำให้เวียนศีรษะ | ผู้ใช้ทดลองไม่สบาย ใช้งานไม่ได้ |
| 3 | ความถูกต้องของเนื้อหาบทเรียนและเสียงระนาด | โน้ตและวิธีฝึกมาจากข้อมูลวิทยาลัยนาฏศิลป์บางส่วนที่ยังไม่ยืนยันกับผู้เชี่ยวชาญ และเสียงในเกมยังเป็นเสียงสังเคราะห์ | สอนผิดหรือเสียงไม่ตรงระนาดจริง |

ผู้ใช้จริงสำหรับ UAT: มีผู้สนใจแล้ว แต่ยังไม่ได้ติดต่อ (ไม่ระบุชื่อ)
